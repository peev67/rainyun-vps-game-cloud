## 动态计费：CPU 低于 20% 只收基础月租

动态计费按 CPU 使用率触发：使用率低于 20% 时只收基础月租，有负载时按实际用量额外计费。计费单位叫"电量"，单价在 0.0005～0.001 元/电量之间。这个单价是区间，不同来源表述略有差异，也没有看到官方定价页原文。

适合的场景很明确：白天上班上学没人上线、晚上才开服的休闲服。空转时段只付基础租金，公开记录里 2核4G 动态计费入门档标到约 15 元/月起。另一份资料的说法是"只有 CPU 实际跑满了才按电量额外日结算"，措辞不同，共同点都是低负载只收基础租金。

不适合的场景同样明确：7×24 满负载跑整合包，或者拿游戏云兼职跑计算任务。CPU 长期停在高位，电量费会持续叠加，最后未必比固定月付便宜。官方给这套模式配的宣传语是"让天下服主安心睡觉"，指向的就是夜间空载那段时间。

## 面板服和 VPS 差在哪：权限、上行、能不能装别的

三个差异决定了你该选哪种。

**系统权限**。面板服没有系统级登录权限，全程网页操作：选版本、上传核心、分配内存、点启动，跑的是 Paper / Purpur / Spigot / Fabric 这几种服务端核心。VPS 形态基于 KVM，给完整系统权限，Windows 和 Linux 都能装，可以 SSH 或远程桌面进去自己搭环境。

**上行带宽**。面板服固定 50Mbps 上行，VPS 形态按套餐选，常见的是 10M 和 15M。这里有个反直觉的地方：同价位下面板服的上行反而更高。MC 服真正吃紧的是上行，十来个人同时在线时 10M 上行容易顶到天花板，50Mbps 能明显缓解。代价是没有 root。

**能不能装别的**。VPS 形态最多支持 15 个端口映射、带手动备份、可以多端同开，一台机器顺便放个网站或机器人没问题。面板服只能跑面板支持的那些服务端。VPS 形态可选独立 IP 或 NAT 端口映射，NAT 机型没有独立 IP，靠端口映射对外，对 MC 服够用；要跑对端口有特殊要求的服务，得加购独立 IP。

面板本身归谁开发，两份资料说法不一，一份称基于 MCSManager，一份称是雨云自研，没有官方页面确认。这点不必纠结，实际操作路径是一样的。如果你是第一次开服，面板服的省心程度对得起它的配置限制。👉 [查看面板服与 VPS 的当前配置和价格](https://bit.ly/RaiNyun)

## 第三方实测：延迟和丢包对得起价格，硬件要看清

2026 年 9 月那份洛杉矶测评的数据：本地移动网络 ping 平均 182ms，基本不丢包；全国三网平均 163ms，其中电信 172ms、联通 157ms、移动 158ms；港澳台及东南亚 147ms。测试方法是全球海内外近 100 个节点各 ping 100 下，国内外基本都没有丢包。

路由走向：去程电信走 163 骨干、联通走 AS9929、移动走 CMI；回程电信和联通走 AS9929、移动走 CMI。AS9929 是联通系的高端线路，比普通 163 骨干延迟低、丢包少，价格又比 CN2 GIA 亲民，美国节点能做到 160ms 出头是这条线路的功劳。

硬件需要单独说。这台被测的美国 VPS 用的是 Intel E5-2680 v4，主频 2.40GHz，磁盘 I/O 1500MB/s，本地下载 5.5MB/s。E5-2680 v4 是上一代至强，和国内游戏云主推的 9950X、14900K 完全不是一个档次的硬件。14900K 那档是水冷、单核最高 6.3GHz，4核8G 机型单核 Geekbench 6 约 2830 分。**高主频宣传只对应特定的游戏云套餐，不是全线配置。** 买 20 元美国节点图的是价格和线路，别指望单核性能；反过来，买高主频游戏云也别拿美国节点的价格去对标。

其他节点的延迟，另一份未注明测试方法的记录给的是：香港 CMI + AS9929 实测 30～60ms，日本 CN2/CMI 50～80ms，美国洛杉矶 150～200ms。国内节点里镇江 BGP 对大陆用户体感延迟较低，游戏云库存曾出现过补货情况。

长期稳定性只有一个小样本：2024 年一份个人记录，湖北十堰 2vCPU / 2G / 30M上60M下 的机器连续用了 40 天，除了自己重启之外没有断开过。一台机器、40 天，只能当参考，不能当 SLA。
